# 画像モザイク工房 v1.1

画像をブラウザ内で編集する、日本語の静的Webアプリです。PNG / JPEG / WebPを読み込み、モザイクや不透明な塗りつぶしを適用できます。外部ライブラリ、CDN、画像アップロード、解析通信はありません。

## 起動
ZIPを展開し、`index.html`をChromeまたはEdgeで開いてください。インターネット接続やインストールは不要です。ファイル一式を同じフォルダーに保ってください。推奨環境はWindows 11のChrome / Edge。その他のブラウザ・スマートフォンは未検証です。

## iPhoneで写真に保存
1. GitHub PagesのHTTPSのURLをSafariで開き、画像を加工します。
2. 保存形式を選び、「写真に保存・共有」を押します。
3. 画像の準備後、「共有画面を開く」を押します。
4. 共有画面に「画像を保存」が表示されたら選び、「写真」アプリで確認します。

保存項目の有無・名称はiOSやブラウザによって異なります。共有が使えない／保存項目がない場合は、表示された加工済み画像を長押しして保存メニューをご確認ください。アプリ内ブラウザではSafariで開き直してください。既存のファイルダウンロードも利用できます。

Webアプリから写真ライブラリへの無操作の直接書き込みは行いません。画像の生成と共有操作を分け、ボタン操作直後にWeb Share APIを呼び出します。共有の完了通知は写真への保存完了を保証しないため、アプリでは保存成功を断定しません。共有先を選んだ場合はOSがその先へファイルを渡します。

iPhone実機での共有シート・写真への保存は未検証です。

## 操作
1. 画像を選択、またはウィンドウへ1枚ドロップ。
2. モザイク / 塗りつぶしを選ぶ。
3. クリック・なぞる / 四角く囲むを選んで画像上を操作。
4. 必要に応じて粒・ブラシの大きさ、形、色を調整。
5. PNG / JPEGを選び「ファイルとして保存」。

Ctrl+Z: 元に戻す。Ctrl+Shift+ZまたはCtrl+Y: やり直す（Macは⌘も可）。Escape: 描画中の操作をキャンセル。拡大時は編集領域のスクロールバーで移動。

## GitHub Pagesで公開
1. GitHubでリポジトリを作成し、ZIPを展開したフォルダーの**中身**をリポジトリのルートへアップロードします。`index.html`が直下にあることを確認してください。
2. Settings → Pages → Build and deployment の Source を **Deploy from a branch** にします。
3. Branch は **main**、フォルダーは **/(root)** を選び Save。
4. 公開処理完了後、Pagesに表示されるURLを開きます。通常は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

ビルド工程やnpmは不要です。`.nojekyll`を同梱しています。ホスティング先へのアクセス時はページ取得の通信が発生しますが、選択画像の送信処理はありません。編集画像をリポジトリへ追加する必要はありません。

公式手順（2026-09-24確認）:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 仕様・制約
- 入力: PNG / JPEG / WebP、1枚50 MB以下、5,000万画素以下、各辺16,000 px以下。端末のメモリによっては上限以下でも開けません。
- 出力: 元の縦横ピクセル数のPNG、または品質95%のJPEG。JPEGの透過部分は白。元ファイルは上書きしません。
- 元ファイルのEXIF等はコピーしません。元画像の色空間・ICC・HDR・ビット深度の保持は保証しません。画素数の保持と元ファイルの完全保持は異なります。
- アニメーション画像は対象外です。静止画像を使用してください。HEIC・RAW・SVGは非対応。
- 1枚ずつ編集。履歴は500操作まで。クリック／ドラッグ1回が1操作です。履歴再生時は大画像・多数操作で時間がかかります。
- 画像・編集履歴の永続保存やプロジェクト保存はありません。ページを閉じる前に画像を書き出してください。全リセットは履歴も削除します。
- モザイクは情報の完全な秘匿を保証しません。文字などは不透明な塗りつぶしで余裕を持って覆い、保存画像を確認してください。
- 保存先はブラウザが管理します。アプリから実際の保存完了や保存パスは取得できないため、ダウンロード開始とファイル名を案内します。

## ファイル
- index.html: 編集画面
- raster.js: 境界に半透明のふちを作らないピクセル置換処理
- share.js: 写真保存用プレビュー・ファイル共有・非対応時の案内
- app.js: 画像処理・操作（VERSION定数でアプリのバージョンを管理）
- style.css: レイアウト
- manual.html: 日本語マニュアル（画面から開けます）
- README.md: 概要・公開手順
- .nojekyll: GitHub Pages用

今回はWebアプリ指定のためPython、requirements.txt、exeビルドは不要です。PowerShellのExecutionPolicy変更も不要です。

## 旧版からの更新
GitHubのファイル一式を今回の中身に置き換えてください。`raster.js`と`share.js`も必ず追加します。画面が古いままならCtrl+F5で再読み込みし、v1.1表示を確認してください。修正前に保存した画像の線は自動では消えないため、元画像から加工し直してください。

## 軽量化について
v1.0.2ではドラッグ中に触った256pxタイルを再利用し、読み戻しを減らしました。行単位・32bit RGBA値の置換とrequestAnimationFrameによる反映の集約を採用しています。ブラシの軌跡は省略せず保持します。カーソルの消去範囲も前回の表示範囲に限定しました。保存する画像のピクセル数は変更しません。

1920×1080・丸ブラシ256px・160回の描画を使ったNode.jsのメモリ上比較では、v1.0.1と出力が全ピクセル一致し、Canvas読み戻し回数は480→8、書き込み回数は480→84でした。これは模擬Canvasでの確認であり、ブラウザでの実測速度ではありません。大画像の読み込み、最初のモザイク生成、長い履歴の取り消しには待ち時間が発生する場合があります。

## 変更履歴
- v1.1: 「写真に保存・共有」を追加。ファイル共有、長押し用プレビュー、共有非対応・キャンセル・失敗時の案内に対応。
- v1.0.2: ドラッグ単位のタイルキャッシュ、行単位のピクセル置換、フレーム単位の描画反映、カーソル消去範囲の限定により描画負荷を削減。
- v1.0.1: 重ね塗りで円弧状の細いふちが残る不具合を修正。アンチエイリアス付きクリップでの消去・描画から、選択ピクセルのRGBA値の直接置換へ変更。境界は1ピクセル単位となり、高倍率では段差が見えます。
- v1: 初版。モザイク・塗りつぶし、丸／四角ブラシ、範囲指定、拡大表示、取り消し・やり直し、PNG／JPEG保存、ローカル起動・GitHub Pages対応。
